## 格式说明

每条记录包含以下字段：
- 设备型号
- 系统版本（Android API 级别）
- WPS 版本（包名 + 版本号）
- SMB 协议版本
- 测试用例
- 结果（PASS / FAIL / PARTIAL / NOT_RUN）
- 已知限制
- 验证日期

## 三层兼容性模型

### 第一层：通用架构兼容
- 不绑定品牌/WPS 版本
- 通过 Android 标准 API + SMB 适配层 + 文件编辑交接层降低耦合

### 第二层：代表性环境验证
- 初始基线设备：荣耀 9X
- 逐步扩展设备/版本组合

### 第三层：兼容性证据管理
- 每组合记录完整测试结果
- 未实测标"未验证"
- "未验证"允许尝试运行，不得宣称兼容
