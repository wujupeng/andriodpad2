# 0. 问题背景与当前状态

## 0.1 问题：共享目录查看方式单一，无法切换视图模式

**现象**：在 PAD2 的 SMB 共享目录浏览页（BrowsePage），目录内容仅以一种行布局方式呈现（图标 + 文件名 + 大小/时间副标题的列表行），用户无法选择其他查看方式。用户期望类似 Windows 资源管理器的多种查看方式：大图标、中图标、小图标、平铺、详细信息等可切换。

**当前架构事实（代码证据）**：

| 证据编号 | 代码位置 | 事实 |
|---------|---------|------|
| EV-VM-01 | `src/ui/pages/BrowsePage/index.tsx:256-269` | 浏览页展示区仅有一个 `<FileList .../>` 容器，无视图模式切换入口，无第二套展示组件 |
| EV-VM-02 | `src/ui/pages/BrowsePage/index.tsx:228-239` | toolbar 操作区仅含 `SearchField` + `SortMenu` + 多选入口（icon-multiselect），无视图模式切换按钮 |
| EV-VM-03 | `src/ui/pages/BrowsePage/FileList/index.tsx:31,52-107` | `FileList` 固定 `ROW_HEIGHT = 64` 虚拟化行列表，仅渲染 `FileRow` 行布局，无网格布局分支 |
| EV-VM-04 | `src/ui/pages/BrowsePage/FileRow/index.tsx:82-99` | `FileRow` 为 `ListRow` + 24px 图标 + 文件名 + 副标题（"大小 · 修改时间"或"文件夹"）的单一行布局，无图标尺寸分级 |
| EV-VM-05 | `src/state/browseContextStore.ts:24-31` | `BrowseContextEntry` 含 `sort` / `searchQuery` 字段，无 `viewMode` 字段，浏览上下文不承载视图模式 |
| EV-VM-06 | `src/state/uiPrefsStore.ts:12-19,55-60` | 界面偏好 `pad2.prefs.v1` 含 `themeMode` / `sideNavCollapsed`，无视图模式字段，可在 version 1 框架内兼容扩展（与既有字段同模式） |
| EV-VM-07 | `src/ui/pages/BrowsePage/SortMenu/index.tsx:44-87` | `SortMenu` 已实现 BottomSheet + ListRow 选择菜单模式（入口图标 + 缩写徽章 + BottomSheet 选项列表），可复用此模式构建视图模式切换菜单 |
| EV-VM-08 | `src/ui/icons/fileTypeIcons.ts` | `fileIcon()` 已实现文件扩展名 → 图标名映射，图标组件支持 `size` 参数，可按视图模式分级传参 |

**根因结论**：BrowsePage 展示链硬编码为单一行布局（FileList 虚拟化行列表 → FileRow → ListRow 24px 图标），无视图模式状态字段、无切换入口、无网格布局展示组件。界面偏好 store（uiPrefsStore）与浏览上下文 store（browseContextStore）均无 viewMode 字段可供承载。需新增视图模式状态、切换入口、网格布局展示组件，并持久化用户偏好。

**期望**：用户在共享目录浏览页可通过视图模式切换入口在"大图标 / 中图标 / 小图标 / 平铺 / 详细信息"五种模式间切换，所选模式即时生效且跨会话保留，切换不重新请求服务器数据、不影响排序与搜索结果、不丢失多选状态。

# 1. 组件定位

## 1.1 核心职责

本组件负责在共享目录浏览页提供多种视图模式（大图标 / 中图标 / 小图标 / 平铺 / 详细信息）的切换与呈现，实现用户按个人查看习惯选择目录内容展示方式，且偏好跨会话持久保留。

## 1.2 核心输入

1. **用户视图模式切换指令**：用户在浏览页 toolbar 点击视图模式入口并选择目标模式，来源为 BrowsePage 视图模式切换菜单。
2. **当前目录文件列表**：已加载的目录文件条目（含文件名/大小/修改时间/类型/是否目录），来源为 browseContextStore 的 per-profile 浏览上下文（既有，零变更）。
3. **既有排序与搜索状态**：当前排序字段/升降序与搜索关键词，来源为 browseContextStore（既有，视图模式与之正交）。
4. **界面偏好持久化数据**：Preferences 中已保存的视图模式偏好，来源为界面偏好 store 启动水合。

## 1.3 核心输出

1. **返回给用户的响应**：浏览页按所选视图模式呈现目录内容（图标网格或行布局），视图模式入口持久可见当前模式标识。
2. **持久化输出**：视图模式偏好写入 Preferences（界面偏好键，version 框架内兼容扩展），跨会话保留。
3. **推送给用户的通知**：无（视图模式切换为即时静默生效，无成功/失败提示需求）。

## 1.4 职责边界

本组件**不负责**以下事项：

1. **不负责** 文件数据的加载与服务器请求：目录文件列表由既有 browseContextStore.enterDirectory 承载，本组件仅消费已加载的文件条目按所选模式呈现，切换视图模式不触发任何 SMB 请求。
2. **不负责** 修改既有排序与搜索逻辑：视图模式与排序/搜索正交，排序仍由既有 SortMenu + sortedAndFilteredFiles 承载，搜索仍由既有 SearchField 承载，本组件不改变其行为。
3. **不负责** 文件图标的实际图像生成或缩略图预览：图标仍使用既有 fileIcon 扩展名映射，本组件仅按视图模式分级图标尺寸，不生成缩略图。
4. **不负责** per-folder（按文件夹路径）记忆视图模式：本组件视图模式为全局界面偏好（跨共享统一），不按目录路径单独记忆（Windows 每文件夹记忆属未来功能，见非目标）。
5. **不负责** 自定义图标尺寸或自定义列：仅提供预设的五种模式，不支持用户任意指定像素值或拖拽重排列顺序。
6. **不负责** 修改 SmbPlugin 冻结区接口（HC-02）：视图模式为纯 UI 呈现层变更，不触及 SMB 协议层。

# 2. 领域术语

**视图模式（ViewMode）**
: 共享目录内容的呈现布局方式，取值为大图标（largeIcon）/ 中图标（mediumIcon）/ 小图标（smallIcon）/ 平铺（tile）/ 详细信息（detail）五种之一。每种模式决定图标的尺寸分级与条目的布局形态（网格或行）。

**大图标模式（largeIcon）**
: 以网格布局呈现目录条目，每项为最大尺寸图标 + 文件名，网格列数最少，适合视觉浏览场景。

**中图标模式（mediumIcon）**
: 以网格布局呈现目录条目，每项为中等尺寸图标 + 文件名，网格列数居中。

**小图标模式（smallIcon）**
: 以网格布局呈现目录条目，每项为最小尺寸图标 + 文件名，网格列数最多，适合一屏查看更多条目。

**平铺模式（tile）**
: 以行布局呈现目录条目，每行为图标 + 文件名 + 一行摘要信息（大小或"文件夹"标识），信息密度介于图标模式与详细信息之间。

**详细信息模式（detail）**
: 以行布局呈现目录条目，每行为图标 + 文件名 + 大小 + 修改时间 + 类型等多列信息，信息密度最高，为默认模式（等价当前展示，向后兼容）。

**图标尺寸分级**
: 大/中/小图标模式对应的图标尺寸依次递减，网格列数依次递增的相对关系约束。具体像素值属实现细节，本规格仅约束相对大小顺序与模式语义。

**视图模式切换入口**
: 浏览页 toolbar 提供的视图模式选择控件，点击后弹出选择菜单（复用既有 BottomSheet 选择模式），入口持久可见当前模式标识。

# 4. DFX 约束

## 4.1 性能

1. **DFX-VM-01 视图模式切换即时生效**：视图模式切换须为纯前端重渲染，不触发任何 SMB 网络请求，切换后在 100ms 内完成新布局呈现。
   - 验收条件：[用户选择"大图标"模式] → [目录内容在 100ms 内以网格布局重新呈现，无网络请求发出]
2. **DFX-VM-02 大量条目渲染性能**：图标网格模式须对大量目录条目采用虚拟化或分屏渲染策略，避免一次性渲染数千 DOM 节点导致卡顿。
   - 验收条件：[目录含 1000+ 文件，切换到大图标模式] → [页面滚动流畅，不出现明显卡顿或内存溢出]

## 4.2 可靠性

1. **DFX-VM-03 视图模式偏好持久化失败不崩溃**：Preferences 写入失败或读取损坏时，须安全降级为默认视图模式（详细信息），不崩溃，不阻塞浏览。
   - 验收条件：[Preferences 损坏/写入异常] → [视图模式回默认详细信息，浏览页正常呈现目录内容]
2. **DFX-VM-04 视图模式与连接状态无关**：视图模式切换不依赖 SMB 连接状态，即使在 network_lost 等非理想连接态，已加载的目录内容仍可切换视图模式查看。
   - 验收条件：[连接态为 network_lost 且目录已有缓存内容] → [用户仍可切换视图模式查看缓存内容]

## 4.3 安全性

1. **DFX-VM-05 视图模式不涉及敏感数据**：视图模式偏好仅为枚举值，不携带任何凭据/路径/文件内容等敏感信息，持久化不新增敏感字段。
   - 验收条件：[检查视图模式持久化数据] → [仅为模式枚举字符串，不含敏感字段]

## 4.4 可维护性

1. **DFX-VM-06 视图模式偏好持久化可观测**：视图模式偏好须持久化到 Preferences，跨会话保留用户偏好，且持久化键与既有界面偏好键协调（不冲突、可兼容扩展）。
   - 验收条件：[用户设置"中图标"后彻底重启应用] → [浏览页视图模式保留为"中图标"]

## 4.5 兼容性

1. **DFX-VM-07 既有界面偏好数据兼容**：新增视图模式字段须在既有 Preferences 键的 version 框架内向后兼容扩展，旧数据缺失字段视为默认详细信息模式（不升级版本号，不安全丢弃用户既有偏好）。
   - 验收条件：[既有无视图模式字段的偏好数据加载] → [视图模式视为默认详细信息，既有 themeMode/sideNavCollapsed 等偏好完整保留]
2. **DFX-VM-08 默认视图模式等价当前展示**：默认视图模式（详细信息）的呈现须与当前 FileRow 行布局视觉等价（图标 + 文件名 + 大小/时间副标题），保证既有用户无感升级。
   - 验收条件：[首次使用/无持久化视图模式的用户进入浏览页] → [目录以当前行布局方式呈现（详细信息模式），视觉与升级前一致]

# 5. 核心能力

## 5.1 视图模式切换与多模式呈现（REQ-VM）

### 5.1.1 业务规则

1. **REQ-VM-01 多视图模式可选**：WHEN 用户在共享目录浏览页 THEN THE SYSTEM SHALL 在 toolbar 提供视图模式切换入口，支持在大图标 / 中图标 / 小图标 / 平铺 / 详细信息五种模式间选择。
   - 验收条件：[进入共享目录浏览页] → [toolbar 存在视图模式切换入口，点击后弹出含"大图标/中图标/小图标/平铺/详细信息"五个选项的菜单]
   - 验收条件：[视图模式菜单五个选项] → [每项可独立选中，选中后菜单关闭并按该模式呈现]

2. **REQ-VM-02 视图模式切换即时生效不请求服务器**：WHEN 用户选择目标视图模式 THEN THE SYSTEM SHALL 立即按所选模式重新呈现当前已加载的目录文件列表，不向 SMB 服务器重新发起任何请求。
   - 验收条件：[用户从"详细信息"切换到"大图标"] → [目录内容立即以大图标网格呈现，无 listDirectory 网络请求发出]
   - 验收条件：[切换视图模式] → [呈现的文件条目集合与切换前一致（同一份已加载数据）]

3. **REQ-VM-03 视图模式偏好持久化**：IF 用户设置视图模式 THEN THE SYSTEM SHALL 将该偏好持久化到 Preferences，跨会话保留，下次启动浏览页时自动恢复。
   - 验收条件：[设置"小图标"模式后彻底关闭并重启应用，进入共享浏览] → [视图模式自动恢复为"小图标"]

4. **REQ-VM-04 视图模式默认值**：IF 用户未设置视图模式偏好（首次使用或既有数据缺失字段） THEN THE SYSTEM SHALL 默认采用详细信息模式，其呈现与当前 FileRow 行布局视觉等价（向后兼容）。
   - 验收条件：[首次使用/无持久化视图模式] → [默认"详细信息"模式，视觉与当前行布局一致]
   - 验收条件：[既有偏好数据无视图模式字段] → [视图模式视为"详细信息"，既有其他偏好保留（DFX-VM-07）]

5. **REQ-VM-05 视图模式为全局界面偏好**：WHEN 用户在不同 SMB 共享间切换浏览 THEN THE SYSTEM SHALL 视图模式偏好跨共享统一（全局界面偏好），不按共享或目录路径单独记忆。
   - 验收条件：[在共享 A 设置"大图标"后切换到共享 B 浏览] → [共享 B 浏览页视图模式同样为"大图标"]
   - 验收条件：[在共享 A 设置"平铺"后返回共享 A] → [共享 A 视图模式保留为"平铺"（全局偏好，非 per-profile）]

6. **REQ-VM-06 大/中/小图标模式网格布局**：WHEN 视图模式为大图标 / 中图标 / 小图标 THEN THE SYSTEM SHALL 以网格布局呈现目录条目，每项为对应尺寸图标 + 文件名，且图标尺寸按大/中/小依次递减、网格列数按大/中/小依次递增。
   - 验收条件：[选择"大图标"] → [网格布局，每项大尺寸图标 + 文件名，列数最少]
   - 验收条件：[选择"中图标"] → [网格布局，每项中尺寸图标 + 文件名，列数居中]
   - 验收条件：[选择"小图标"] → [网格布局，每项小尺寸图标 + 文件名，列数最多]
   - 验收条件：[对比三种图标模式图标尺寸] → [大图标 > 中图标 > 小图标（尺寸递减）]
   - 验收条件：[对比三种图标模式网格列数] → [小图标列数 > 中图标列数 > 大图标列数（列数递增）]

7. **REQ-VM-07 平铺模式行布局**：WHEN 视图模式为平铺 THEN THE SYSTEM SHALL 以行布局呈现目录条目，每行为图标 + 文件名 + 一行摘要信息（文件显示大小、目录显示"文件夹"标识）。
   - 验收条件：[选择"平铺"模式，目录含文件与子目录] → [每行为图标 + 文件名 + 摘要，文件摘要为大小，目录摘要为"文件夹"]

8. **REQ-VM-08 详细信息模式多列行布局**：WHEN 视图模式为详细信息 THEN THE SYSTEM SHALL 以行布局呈现目录条目，每行包含图标 + 文件名 + 大小 + 修改时间 + 类型等多列信息。
   - 验收条件：[选择"详细信息"模式] → [每行包含图标 + 文件名 + 大小 + 修改时间 + 类型信息]
   - 验收条件：[详细信息模式呈现] → [视觉与当前 FileRow 行布局等价（DFX-VM-08 向后兼容）]

9. **REQ-VM-09 视图模式不影响文件数据与排序**：WHILE 用户切换视图模式 THEN THE SYSTEM SHALL 不改变文件列表内容与当前排序结果，仅改变条目的呈现布局形态。
   - 验收条件：[按名称升序排列后切换到"大图标"] → [网格中条目顺序仍为名称升序，内容不变]
   - 验收条件：[切换视图模式] → [文件条目集合与排序顺序与切换前完全一致]

10. **REQ-VM-10 视图模式与搜索过滤正交**：WHEN 用户在已输入搜索关键词过滤后切换视图模式 THEN THE SYSTEM SHALL 保留当前搜索过滤结果，仅按新模式呈现已过滤的条目。
    - 验收条件：[输入搜索"doc"过滤后切换到"小图标"] → [网格仅呈现名称含"doc"的条目，搜索关键词保留]

11. **REQ-VM-11 空目录与加载态不受视图模式影响**：IF 目录为空或正在加载 THEN THE SYSTEM SHALL 呈现既有 EmptyState（空目录引导）或 Skeleton（加载骨架），不因视图模式变更改变空态与加载态行为。
    - 验收条件：[目录为空时切换视图模式] → [仍呈现 EmptyState"目录为空"引导，不呈现空网格或空列表]
    - 验收条件：[目录加载中时切换视图模式] → [仍呈现 Skeleton 加载骨架，待加载完成后按当前视图模式呈现]

12. **REQ-VM-12 多选态与视图模式兼容**：WHILE 多选模式激活 AND 用户切换视图模式 THEN THE SYSTEM SHALL 视图模式切换入口保持可用，已选中条目在视图模式切换后保留选中状态。
    - 验收条件：[多选态选中 3 项后切换到"大图标"] → [网格中该 3 项仍呈选中态，多选态不退出]
    - 验收条件：[多选态切换视图模式] → [视图模式入口不被禁用，可正常切换]

13. **REQ-VM-13 视图模式入口持久可见当前模式**：WHEN 浏览页 toolbar 渲染 THEN THE SYSTEM SHALL 视图模式切换入口持久可见，并以可识别标识（图标或缩写）指示当前所选模式。
    - 验收条件：[当前模式为"中图标"] → [toolbar 视图模式入口显示"中图标"对应标识（图标或缩写）]
    - 验收条件：[切换到"平铺"] → [入口标识更新为"平铺"对应标识]

14. **REQ-VM-14 禁止项**：禁止视图模式切换触发 SMB 服务器重新请求；禁止视图模式切换丢失已选中条目或退出多选态；禁止视图模式切换改变文件列表内容、排序顺序或搜索关键词；禁止视图模式携带敏感数据；禁止 per-folder 按目录路径单独记忆视图模式（本组件仅全局偏好）。
    - 验收条件：[切换视图模式] → [不发出任何 listDirectory/connect 网络请求]
    - 验收条件：[多选态切换视图模式] → [选中项不丢失，多选态不退出]
    - 验收条件：[切换视图模式] → [文件内容/排序/搜索不变]
    - 验收条件：[检查视图模式持久化] → [仅枚举值，无敏感数据]
    - 验收条件：[在不同目录路径切换] → [视图模式跟随全局偏好，不按路径单独记忆]

### 5.1.3 异常场景

1. **视图模式偏好持久化失败**
   - 触发条件：Preferences.set 写入失败或读取返回损坏 JSON。
   - 系统行为：降级为默认视图模式（详细信息），内存态本次会话生效，不崩溃，不阻塞浏览。
   - 用户感知：本次会话视图模式切换生效，重启后可能回默认详细信息，浏览页正常可用。

2. **视图模式字段值非法**
   - 触发条件：持久化的视图模式值不在 largeIcon/mediumIcon/smallIcon/tile/detail 枚举内（数据篡改或版本不匹配）。
   - 系统行为：降级为默认视图模式（详细信息），不崩溃。
   - 用户感知：浏览页以详细信息模式呈现，不报错。

3. **目录加载失败时切换视图模式**
   - 触发条件：目录加载失败（loadError 非空）时用户切换视图模式。
   - 系统行为：视图模式偏好正常更新并持久化，但展示区呈现既有加载失败 Banner（StatusBanner）而非文件列表，待用户重试加载成功后按新视图模式呈现。
   - 用户感知：切换模式后仍看到加载失败提示与重试按钮，重试成功后按新模式呈现。

4. **大量条目下图标网格渲染压力**
   - 触发条件：目录含大量条目（数百至数千），切换到图标网格模式。
   - 系统行为：采用虚拟化或分屏渲染策略（DFX-VM-02），仅渲染可视区域及缓冲区条目，避免全量 DOM。
   - 用户感知：网格滚动流畅，不出现卡顿或白屏。

5. **多选态下切换视图模式**
   - 触发条件：多选模式激活且已选中若干条目时切换视图模式。
   - 系统行为：视图模式切换正常生效，已选中条目按路径标识在新布局中保留选中态，多选态不退出。
   - 用户感知：切换后选中项仍可见选中标识，可继续批量操作。

# 6. 数据约束

## 6.1 视图模式偏好（ViewMode）

1. **viewMode**：必填，取值为 `largeIcon`（大图标）/ `mediumIcon`（中图标）/ `smallIcon`（小图标）/ `tile`（平铺）/ `detail`（详细信息）五种枚举之一。
2. **默认值**：未持久化或字段缺失时默认 `detail`（详细信息，等价当前展示，DFX-VM-08 向后兼容）。
3. **全局偏好**：viewMode 为全局界面偏好，跨共享与跨目录路径统一，不按 profile 或路径分区（REQ-VM-05）。
4. **持久化兼容**：viewMode 在既有界面偏好键的 version 框架内向后兼容扩展，旧数据缺失字段视为 `detail`，不升级版本号，不破坏既有 themeMode/sideNavCollapsed 等偏好（DFX-VM-07）。
5. **非法值降级**：持久化的 viewMode 值不在枚举内时降级为默认 `detail`，不崩溃（异常场景2）。
6. **不携带敏感数据**：viewMode 仅为枚举字符串，不含凭据/路径/文件内容等敏感信息（DFX-VM-05）。

## 6.2 图标尺寸分级约束

1. **尺寸递减关系**：大图标模式图标尺寸 > 中图标模式图标尺寸 > 小图标模式图标尺寸（严格递减）。
2. **列数递增关系**：大图标模式网格列数 < 中图标模式网格列数 < 小图标模式网格列数（严格递增）。
3. **行布局模式图标**：平铺与详细信息模式使用行布局，图标尺寸为行布局适配尺寸（不参与网格分级约束）。
4. **文件图标映射不变**：所有模式均使用既有 fileIcon 扩展名映射确定图标种类，仅尺寸按模式分级传参，不新增图标种类。

## 6.3 视图模式与既有状态正交约束

1. **与排序正交**：视图模式不改变 browseContextStore 的 sort 字段，排序结果在所有视图模式下一致呈现（REQ-VM-09）。
2. **与搜索正交**：视图模式不改变 searchQuery，搜索过滤结果在所有视图模式下一致呈现（REQ-VM-10）。
3. **与多选正交**：视图模式不改变 browseStore 的 selection/selectionMode，选中状态按路径标识跨布局保留（REQ-VM-12）。
4. **与文件数据正交**：视图模式不触发 browseContextStore.enterDirectory/refresh，不改变 files 字段（REQ-VM-02）。

# 7. 非目标（明确不做什么）

1. **NON-VM-01**：不负责文件缩略图的实际图像生成或预览——所有模式均使用既有 fileIcon 扩展名映射的矢量图标，仅按模式分级尺寸，不生成图片缩略图（属未来功能）。
2. **NON-VM-02**：不负责 per-folder（按文件夹路径）记忆视图模式——本组件视图模式为全局界面偏好，不按目录路径单独记忆（Windows 每文件夹记忆视图属未来功能，REQ-VM-05 明确全局偏好）。
3. **NON-VM-03**：不负责自定义图标尺寸或自定义列——仅提供预设的五种模式，不支持用户任意指定像素值、自定义网格列数或拖拽重排列顺序。
4. **NON-VM-04**：不负责修改既有排序与搜索逻辑——视图模式与排序/搜索正交，排序仍由既有 SortMenu + sortedAndFilteredFiles 承载，搜索仍由既有 SearchField 承载，本组件不改变其行为（REQ-VM-09/10）。
5. **NON-VM-05**：不负责视图模式切换时的动画过渡效果——本组件仅保证即时切换呈现，切换动画/过渡属视觉增强，非本规格范围。
6. **NON-VM-06**：不负责目录文件数据的加载与服务器请求——文件列表由既有 browseContextStore.enterDirectory 承载，本组件仅消费已加载数据，切换视图模式不触发任何 SMB 请求（REQ-VM-02）。
7. **NON-VM-07**：不负责修改 SmbPlugin 冻结区接口（HC-02）——视图模式为纯 UI 呈现层变更，不触及 SMB 协议层与原生层。
