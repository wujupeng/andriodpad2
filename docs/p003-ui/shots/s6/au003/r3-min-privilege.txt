TASK-AU003-C-11: 最小权限审计 — SMB 账户权限范围
=====================================================
日期: 2026-10-27
审计方法: 运维侧审计 SMB 账户权限

审计内容:
  SMB 账户: debian
  SMB 共享: share (192.168.2.3)
  SMB 路径: /mnt/share/apk/

  当前权限状态:
    - 读取权限: update.json + APK 文件 (用于自动更新下载)
    - 写入权限: 存在 (用于 APK 发布部署)
    - 删除权限: 待运维确认

  最小权限要求 (REQ-AU003-R3-03):
    - 仅授予 /mnt/share/apk/ 读取权限 (读取 update.json + 读取 APK 文件)
    - 无写入/删除/列举全目录权限
    - 应用仅需要读取更新源，不需要写入

  权限收紧建议:
    1. 创建专用 SMB 账户 (如 pad2_update_reader)，仅授予 /mnt/share/apk/ READ 权限
    2. 或修改现有 debian 账户对 /mnt/share/apk/ 的权限为只读
    3. 写入权限仅保留给运维部署使用 (通过其他账户或直接服务器操作)
    4. 实际收紧由运维执行，本任务仅定义需求

  注意:
    - 当前应用使用 debian 账户进行 SMB 连接
    - 凭据整改后 (TASK-AU003-C-03~C-10) 将使用设备受控凭据文件
    - 运维可在轮换凭据时同步收紧权限

结论: SMB 账户权限须收紧至仅读。实际收紧由运维执行。
