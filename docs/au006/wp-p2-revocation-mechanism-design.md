# WP-P2 凭据撤销机制设计 — 撤销步骤 + 应用行为 + 恢复流程

> **任务编号**：TASK-AU006-P2-04
> **工作包**：WP-P2 专用应用账户设计
> **关联需求**：REQ-P2-05、REQ-P2-08、REQ-P2-10、REQ-DFX-SEC-05、REQ-DFX-REL-04、数据约束 6.2
> **前置依赖**：TASK-AU006-P2-01（专用账户已设计）、TASK-AU006-P2-02（凭据存储方案已选型）
> **工作单元性质**：仅设计（Design-Only），不实施任何服务器账户变更。
> **授权边界**：仅授权设计文档产出，不授权执行 smbpasswd -x 或任何服务器变更。

## 1. 设计目标

为专用账户 `pad2_app` 设计凭据撤销机制，使安全事件时可即时禁用专用账户，旧凭据即时失效，应用感知后禁用写回并提示用户，恢复流程支持凭据恢复后重新启用写回。

**核心设计决策**：
- 撤销方法：`smbpasswd -x pad2_app`（禁用 SMB 账户）
- 应用感知：下次连接收到认证失败（≤3s，非超时）
- 应用行为：禁用写回 + 提示"凭据已失效"
- 恢复流程：`smbpasswd -a pad2_app`（新密码）→ 应用更新 Keystore → 恢复写回

## 2. 撤销触发条件

### 2.1 触发条件矩阵

| 触发类型 | 触发条件 | 触发方 | 紧急程度 | 追溯需求 |
|---------|---------|--------|---------|---------|
| 确认泄露 | 确认凭据已泄露（如密码明文被截获） | 运维 + 安全审查 | 紧急（立即） | REQ-P2-05、REQ-DFX-SEC-05 |
| 疑似泄露 | 疑似凭据泄露（如异常访问日志） | 运维 + 安全审查 | 紧急（立即） | REQ-P2-05 |
| 设备丢失 | 存储凭据的设备丢失/被盗 | PM + 运维 | 紧急（立即） | REQ-DFX-SEC-05 |
| 内部违规 | 内部人员违规使用凭据 | PM + 安全审查 | 高（尽快） | REQ-P2-05 |
| 账户停用 | PAD2 应用停用/下线 | PM | 中（计划性） | REQ-P2-05 |
| 安全审计 | 安全审计要求撤销 | 安全审查 | 中（计划性） | REQ-P2-05 |

## 3. 撤销步骤

### 3.1 撤销步骤矩阵

| 阶段 | 步骤 | 执行方 | 命令/操作（设计，不执行） | 追溯需求 |
|------|------|--------|-------------------------|---------|
| 1. 触发 | 确认撤销触发（安全事件） | 运维 + PM | 记录触发原因与时间戳 | REQ-P2-05 |
| 2. 服务器撤销 | 禁用 SMB 账户 | 运维 | `sudo smbpasswd -x pad2_app` | REQ-P2-05 |
| 3. 撤销验证 | 确认账户已禁用 | 运维 | `sudo pdbedit -L | grep pad2_app`（预期无输出或标记禁用） | REQ-P2-05 |
| 4. 旧凭据失效 | 旧密码连接测试 | 运维 | `smbclient //192.168.2.3/share -U pad2_app%${SMB_APP_PASSWORD}`（预期失败） | REQ-DFX-SEC-05 |
| 5. 应用感知 | 应用下次连接收到认证失败 | 应用 | 自动（无需人工干预） | REQ-DFX-REL-04 |
| 6. 应用行为 | 禁用写回 + 提示用户 | 应用 | `disableWriteback('凭据已失效')` | REQ-P2-05 |
| 7. 客户端清理 | 清理 Keystore 存储的旧凭据 | 应用 | `credentialStore.revoke('pad2_app')` | REQ-DFX-SEC-05 |
| 8. 审计记录 | 记录撤销审计 | 运维 + 应用 | 记录 timestamp/account/触发原因（不含密码） | REQ-DFX-SEC-08 |

    │                              └─ 否 ──→ [告警 + 手动处理]

## 4. 应用行为设计

### 4.1 应用感知机制

| 感知方式 | 触发条件 | 响应 | 追溯需求 |
|---------|---------|------|---------|
| 连接认证失败 | 下次 SMB 操作时连接收到 `NT_STATUS_LOGON_FAILURE` | 禁用写回 + 提示 | REQ-DFX-REL-04、REQ-P2-05 |
| 主动检测 | 应用启动时连接测试 | 禁用写回 + 提示 | REQ-P2-05 |
| 推送通知 | 运维推送撤销通知（可选） | 禁用写回 + 提示 | REQ-P2-05 |

### 4.2 认证失败识别

| 维度 | 设计值 | 追溯需求 |
|------|--------|---------|
| 失败类型 | `NT_STATUS_LOGON_FAILURE`（认证失败，非超时） | REQ-DFX-REL-04 |
| 响应时间 | ≤ 3s（非模糊超时） | REQ-DFX-REL-04 |
| 错误分类 | `SmbErrorCategory.permission_denied`（经 mapSmbError 映射） | REQ-P4-10 |
| 与网络错误区分 | 认证失败 ≠ 网络中断（`network_lost`/`unreachable`） | REQ-DFX-REL-04 |

### 4.3 应用行为矩阵

| 应用状态 | 撤销后行为 | UI 提示 | 追溯需求 |
|---------|-----------|---------|---------|
| 浏览文件 | 继续浏览（只读，debian 账户仍可用） | "写回功能已禁用：凭据已失效" | REQ-P2-05 |
| 编辑文件中 | 禁止写回，保留本地缓存 | "写回失败：凭据已失效，本地缓存已保留" | REQ-P2-05、REQ-DFX-REL-01 |
| 写回进行中 | 写回失败，保留本地缓存 | "写回失败：凭据已失效，本地缓存已保留" | REQ-P2-05 |
| 另存为中 | 禁止另存为，保留本地缓存 | "另存为失败：凭据已失效" | REQ-P2-05 |
| 应用启动 | 检测凭据失效，禁用写回 | "写回功能已禁用：凭据已失效，请联系管理员" | REQ-P2-05 |

### 4.4 editSessionStore 状态迁移

| 当前状态 | 撤销后状态 | 迁移条件 | 追溯需求 |
|---------|-----------|---------|---------|
| opened | session_terminated | 认证失败 | REQ-P2-05 异常 3 |
| editing | session_terminated | 认证失败（写回时） | REQ-P2-05 异常 3 |
| writeback_pending | writeback_failed → session_terminated | 写回认证失败 | REQ-P2-05 异常 3 |
| saveas_detected | session_terminated | 认证失败 | REQ-P2-05 异常 3 |

## 5. 恢复流程

### 5.1 恢复步骤矩阵

| 阶段 | 步骤 | 执行方 | 命令/操作（设计，不执行） | 追溯需求 |
|------|------|--------|-------------------------|---------|
| 1. 恢复决策 | 确认安全事件已解决，决定恢复 | PM + 安全审查 | 记录恢复决策 | REQ-DFX-SEC-05 |
| 2. 生成新密码 | 生成新密码（不写入文档） | 运维 | `openssl rand -base64 32`（经环境变量注入） | REQ-DFX-SEC-01 |
| 3. 服务器恢复 | 重新启用 SMB 账户 | 运维 | `sudo smbpasswd -a pad2_app`（设置新密码） | REQ-DFX-SEC-05 |
| 4. 服务器验证 | 验证新凭据连接 | 运维 | `smbclient //192.168.2.3/share -U pad2_app -c 'ls writable/'` | REQ-DFX-SEC-05 |
| 5. 客户端更新 | 应用更新 Keystore 存储 | 应用 | `credentialStore.set('pad2_app', newPassword)` | REQ-DFX-SEC-05 |
| 6. 应用恢复 | 恢复写回功能 | 应用 | `enableWriteback()` | REQ-DFX-SEC-05 |
| 7. 恢复验证 | 验证写回功能恢复 | QA | 端到端写回测试 | REQ-DFX-SEC-05 |
| 8. 审计记录 | 记录恢复审计 | 运维 + 应用 | 记录 timestamp/account/恢复原因 | REQ-DFX-SEC-08 |

### 5.2 恢复流程图

```text
[恢复决策] ──PM/安全审查确认──→ [触发恢复]
    │
    ▼
[生成新密码] ──环境变量注入──→ [PAD2_SMB_NEW_PASSWORD]
    │
    ▼
[服务器恢复] ──smbpasswd -a pad2_app──→ [SMB 账户重新启用]
    │
    ▼
[服务器验证] ──smbclient 连接测试──→ [新凭据连接成功?]
    │                                    │
    │                                    ├─ 是 ──→ [继续]
    │                                    └─ 否 ──→ [报错 + 手动处理]
    ▼
[客户端更新] ──credentialStore.set()──→ [Keystore 新凭据存储]
    │
    ▼
[应用恢复] ──enableWriteback()──→ [写回功能恢复]
    │
    ▼
[恢复验证] ──端到端写回测试──→ [写回成功?]
    │                              │
    │                              ├─ 是 ──→ [恢复完成]
    │                              └─ 否 ──→ [排查 + 重试]
    ▼
[审计记录] ──timestamp/account/原因──→ [审计日志（不含密码）]
```

| 维度 | 恢复后状态 | 追溯需求 |
|------|-----------|---------|

| Keystore | 新密码已加密存储 | REQ-DFX-SEC-05 |
| 写回功能 | 已恢复（`WRITE_ENABLED_SCOPE.enabled = true`） | REQ-DFX-SEC-05 |

## 6. 撤销审计

### 6.1 审计日志结构

```typescript
interface RevocationAuditEntry {
  timestamp: number;           // 撤销/恢复时间戳
  account: string;             // 账户名（如 'pad2_app'）
  action: 'revoke' | 'restore'; // 撤销或恢复
  triggerReason: string;       // 触发原因（不含密码）
  result: 'success' | 'failed';
  failureReason?: string;      // 失败原因（不含密码）
  operator: string;            // 执行人
  // 不含 password、passwordHash
}
```

### 6.2 审计保证

| 审计项 | 保证 | 追溯需求 |
|--------|------|---------|
| 记录内容 | timestamp/account/action/triggerReason/result | REQ-DFX-SEC-08 |
| 禁止记录密码 | 不含 password/passwordHash | REQ-DFX-SEC-01、REQ-DFX-SEC-08 |
| 即时记录 | 撤销/恢复后立即记录 | REQ-DFX-SEC-08 |
| 持久化 | 经 SmbPlugin.exportLog 或本地审计文件 | REQ-DFX-SEC-08 |

## 7. 异常场景

### 7.1 撤销后应用未感知

| 维度 | 说明 | 追溯需求 |
|------|------|---------|
| 触发条件 | 账户已撤销但应用未重启或未重连 | REQ-P2-05 异常 3 |
| 系统行为 | 下次写回操作时收到认证失败，转入 `session_terminated` | REQ-P2-05 异常 3 |
| 用户感知 | 写回失败 + "凭据已失效"提示 | REQ-P2-05 异常 3 |
| 恢复 | 应用自动禁用写回，等待凭据恢复 | REQ-P2-05 |

### 7.2 撤销失败

| 失败原因 | 处理 | 追溯需求 |
|---------|------|---------|
| `smbpasswd -x` 失败（权限不足） | 记录失败，账户仍启用，告警 | REQ-P2-05 |
| `pdbedit` 验证失败 | 记录失败，手动确认账户状态 | REQ-P2-05 |

### 7.3 恢复失败

| 失败原因 | 处理 | 追溯需求 |
|---------|------|---------|
| `smbpasswd -a` 失败 | 记录失败，账户仍禁用，写回不可用 | REQ-DFX-SEC-05 |
| Keystore 更新失败 | 服务器已恢复但客户端未更新，触发轮换异常 7.1 | REQ-DFX-SEC-05 |
| 端到端验证失败 | 排查原因，可能须重新恢复 | REQ-DFX-SEC-05 |
